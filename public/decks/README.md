# Course decks

Drop any `.html` deck file directly into this folder and redeploy — the
`/courses` page (`src/app/courses/page.tsx`) automatically lists every
`.html` file found here, no code change needed.

This folder (and this README) ships as a static asset, so the README itself
will technically be downloadable at `/decks/README.md` — harmless, but you
can delete it once real decks are in here if that bothers you.

Naming tip: the page turns the filename into the display title
(`session-01-intro-to-finance.html` → "Session 01 Intro To Finance"), so
name files the way you want them to read.
